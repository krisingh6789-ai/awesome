ABHYAS — POLITY & ECONOMY READING REVISION
19 September 2026

1. Extract this ZIP into a folder on your phone.
2. For the interactive app, open Abhyas-Offline.html in a browser.
3. Choose Study → Open Polity & Economy.
4. Choose Polity or Economy, open a part, and select a chapter.
   “Read this entire part” combines its chapters into one reading screen.
5. Practice & notes opens the study tools separately from reading.

JUST WANT TO READ?
Open Abhyas-Polity-Reading-Book.html or
Abhyas-Economy-Reading-Book.html. They are standalone read-only books,
need no JavaScript or network, and include linked contents and sources.
To make a PDF, use your browser's Print → Save as PDF if supported.
External source links require internet. No arbitrary page limit is applied.

YOUR SAVED WORK
Export a backup from the OLD app before replacing it. Import it into the
new app if needed. Use the same browser/profile and location where possible.
Progress and notes require browser storage; read-only books do not save them.
This is HTML, not an APK. Android file opening and storage restrictions vary;
physical Android use has not been verified. If a file viewer blocks scripts,
use a browser or read the separate subject books. No personal files are in
this public download. Online AI still needs your configured backend.
